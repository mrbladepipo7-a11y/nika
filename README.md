# THE LAST LINE

An atmospheric interactive web experiment inspired by an abandoned tram swallowed by the forest.

## Features
- Full-screen cinematic hero
- Image-based parallax movement
- Animated scanline + film grain
- Interactive recovered terminal
- Field-note modal
- Choice-based ending
- Responsive mobile layout
- No framework required

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your site will be available at your GitHub Pages address.
